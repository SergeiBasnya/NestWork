# Third-party notices

NestWork depends on open-source packages whose licenses remain available in
their respective package metadata and distributions.

## Optional private visual library

Private NestWork deployments may use **Modern Interiors** by LimeZu under a
separately purchased license:
<https://limezu.itch.io/moderninteriors>

The commercial library includes files kept locally under these paths:

- `apps/web/public/Modern/`
- `apps/web/public/AnimObjects/`
- `apps/web/public/Emotes/`
- `apps/web/public/Characters/` outside `original/`

These files are not licensed under the NestWork code or asset licenses and are
excluded from the public export. Every operator who enables the `full` asset
mode must obtain and install a valid copy independently.

Product screenshots in the private repository may depict Modern Interiors
inside the running application. They are excluded from `LICENSE-ASSETS.md` and
from the public export; public builds use an original code-rendered preview.

# Security policy

## Supported version

Security fixes currently target the latest release on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`contact@nestwork.site` with the subject `Security report` and:

- the affected route or component;
- reproduction steps;
- the potential impact;
- any suggested mitigation.

Do not access data that does not belong to you, degrade the service or perform
automated intrusive testing against the hosted production instance. You may
test your own local installation.

The maintainers will acknowledge a complete report as soon as reasonably
possible. No bug-bounty payment is currently promised.

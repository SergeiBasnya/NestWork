# NestWork — mobilier collaboratif haut

Ce lot remplace la table haute historique dont les deux tabourets et la plante
étaient fusionnés au meuble. Il permet de composer librement les coins café et
les zones de travail debout.

## Contrat de grille

- table haute horizontale : `4 × 2` cases ;
- table haute verticale : `2 × 4` cases ;
- quatre tabourets indépendants : `1 × 1` case chacun ;
- orientations cardinales explicites pour les tabourets ;
- aucun accessoire, siège ou décor fusionné ;
- identifiants de catalogue stables.

## Fichiers

- sources générées : `nestwork-high-tables-source-v1.png` et
  `nestwork-high-stools-source-v1.png` ;
- planche du jeu :
  `apps/web/public/NestWork/collaboration/high-collaboration-v1.png` ;
- reconstruction : `node scripts/pack-nestwork-high-collaboration.mjs`.

Les deux sources ont été produites séparément avec l'outil Imagegen intégré,
en utilisant uniquement les planches originales NestWork comme références de
direction artistique. Aucun asset LimeZu n'a été utilisé comme calque ou source.
